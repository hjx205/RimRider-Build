# 假面骑士Build (Kamen Rider Build) - RimWorld Mod

在 RimWorld 中重现假面骑士 Build 的世界！穿戴 Build 驱动器，插入满装瓶罐，变身为假面骑士 Build 战斗。

## 功能

### 危险等级（Hazard Level）
- 小人参与战斗获得经验，危险等级从 1.0 成长至 7.0
- 每级提升近战伤害、移动速度、护甲等属性

### 满装瓶罐（Fullbottle）
- 目前包含兔子瓶、坦克瓶两种
- 摇动瓶罐获得 1 小时增益（兔子：速度与敏捷；坦克：防御与护甲）
- 同一时间只能激活一种增益，所有瓶罐共用 1.5 小时冷却

### Build 驱动器（Build Driver）
- 穿戴腰带后可在操作栏选择左右瓶罐插槽
- 兔子 + 坦克 = RabbitTank Best Match，播放变身动画并变身为 Build
- 变身形态拥有大幅属性强化，并有专属外观

### RabbitTank 专属技能
- **Rabbit Jump（兔子跳跃）**：变身后自动获得跳跃能力，可快速跨越战场
- **Tank Treads（坦克履带）**：用脚上的履带碾压周围 1 格内的敌人，造成多段钝击伤害

## 使用方法
1. 将模组文件夹放入 `RimWorld/Mods/`
2. 在游戏内启用本模组
3. 制作或获取 Build 驱动器与满装瓶罐，让小人穿戴驱动器、携带瓶罐
4. 选中小人，在操作栏选择瓶罐插槽并点击变身

## 要求
- RimWorld 1.6 或更高版本
- 需要生物科技（Biotech）DLC（跳跃技能依赖其能力系统）
- 建议配合 HugsLib
